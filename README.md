Neural Machine Translation (NMT) aims to automatically translate a sentence from one natural language into another using learned representations. This project investigates a compact French-to-English NMT system for short sentences and focuses on the effect of an attention mechanism on a recurrent encoder-decoder baseline. The central problem addressed is the limitation of representing the complete source sentence through a single fixed-length context vector.
A GRU-based sequence-to-sequence encoder-decoder model is implemented as the baseline, with teacher forcing used during training. A second model extends the baseline with Bahdanau attention, allowing the decoder to assign different weights to the encoder's intermediate hidden states at each decoding step. This provides a direct experimental comparison between fixed-context decoding and dynamically weighted source representations.
The implementation uses a filtered French-English parallel corpus derived from Tatoeba and distributed through ManyThings.org. After filtering for short sentences and selected English prefixes, 17,129 sentence pairs are used. The data are split into 11,990 training pairs, 2,569 validation pairs, and 2,570 held-out test pairs. Text is normalized and tokenized at the word level, with PAD, SOS, EOS, and UNK tokens. Both models use a hidden size of 128, batch size 64, Adam optimization with learning rate 0.001, NLLLoss with padding ignored, and 20 training epochs. Corpus-level BLEU is calculated over the complete test set.
The baseline achieves a corpus BLEU score of 0.2225, while the attention-based model achieves 0.4707, an absolute improvement of 0.2482. Qualitative examples and the attention heatmap further illustrate how the attention model can use different source positions during decoding.
